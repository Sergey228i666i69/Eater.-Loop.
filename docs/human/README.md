# Документация Для Человека

Эта папка - практические инструкции для автора игры. Здесь минимум
программирования и максимум действий в Godot Editor: что открыть, что
скопировать, какие поля настроить и чем проверить результат.

7. [Проверка, сборка и частые проблемы](testing-export-troubleshooting.md).

## Главное Правило

Новый контент почти всегда лучше начинать с шаблона:

- уровень: `levels/templates/cycle_level_template.tscn`;
- простой интерактив: `objects/interactable/templates/basic_interactive_template.tscn`;
- лабораторный ноутбук: `objects/interactable/templates/lab_laptop_template.tscn`;
- холодильник с кормлением: `objects/interactable/templates/feeding_fridge_template.tscn`.

Так меньше ручных ошибок: шаблоны уже проходят проверки проекта.

## Что Считать Успешным Изменением

- Игра открывается в Godot без красных ошибок.
- Новая сцена запускается и ведёт туда, куда должна.
- Все видимые игроку тексты есть на русском и английском.
- Объекты имеют понятные подсказки.
- Двери, ключи, холодильники, ноутбуки и кровати настроены через Inspector,
  а не "держатся в голове".
- `bash tests/run_tests.sh` проходит перед серьёзным сохранением/релизом.
