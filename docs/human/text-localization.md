# Текст И Локализация

Весь текст, который видит игрок, должен быть в таблице переводов:

```text
global/localization/texts.csv
```

В таблице три колонки:

- `keys`;
- `ru`;
- `en`.

## Как Добавить Новый Текст

1. Открой `global/localization/texts.csv` в редакторе, который сохраняет UTF-8.
2. Добавь новую строку.
3. Заполни `keys`, `ru`, `en`.
4. Сохрани файл.
5. Открой Godot, чтобы он обновил импорт переводов.
6. Запусти тесты перед коммитом.

## Какой Key Выбрать

Есть два нормальных варианта:

- semantic key, например `level15.basement.door_locked`;
- сама русская строка, если похожие поля в проекте уже используют такой стиль.

Не добавляй translit-фразы вроде `otkroy_dver` или `najmi_knopku`. Такие ключи
трудно читать и тесты проекта специально ловят новые плохие варианты.

## Текст В Inspector

Если ты в Inspector пишешь `prompt_text`, сообщение двери, note text или hint:

1. Убедись, что такая строка есть в `texts.csv`.
2. Заполни английский перевод.
3. Не копируй текст из мессенджеров/браузера, если видишь странные символы.

## Текст В Скрипте

Если текст задаётся в коде, он должен идти через перевод:

```gdscript
UIMessage.show_notification(tr("level15.basement.door_locked"))
```

Не добавляй новый прямой player-facing текст в кавычках без записи в CSV.

## Что Считается Player-Facing

Добавляй в CSV:

- prompt интерактивов;
- сообщения locked doors;
- note text;
- подсказки;
- тексты лабораторных;
- сообщения денег/награды;
- death/ending тексты;
- gamepad hints;
- кнопки меню, если они видны игроку.

Технические подписи редактора, имена узлов и внутренние ID переводить не нужно.

## Частые Ошибки

- Есть русский текст, но нет английского.
- Key отличается пробелом или регистром.
- В CSV появились битые символы после копирования.
- В сцене написали новый prompt, но забыли таблицу.
- В коде добавили `UIMessage.show_*("Русский текст")` напрямую.
