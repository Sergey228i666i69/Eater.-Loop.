# Мини-Игры, Ноутбуки И Холодильники

Эти системы лучше настраивать через готовые шаблоны и Inspector. Код нужен
только если создаётся новый тип мини-игры или новое поведение.

## Лабораторный Ноутбук

1. Скопируй `objects/interactable/templates/lab_laptop_template.tscn`.
2. Перенеси копию в нужную папку или вставь instance в уровень.
3. В Inspector настрой:
   - `lab_completion_id` - уникальный ID задания;
   - `minigame_scene` - сцена мини-игры;
   - `time_limit` - время на прохождение;
   - `penalty_time` - штраф за провал.

`lab_completion_id` должен быть стабильным. Если холодильник или другой объект
ждёт завершения лабораторной, он будет ссылаться именно на этот ID.

## Timed Lab Мини-Игра

Для обычных лабораторных мини-игр сцена должна работать как timed lab:

- есть успешное завершение;
- есть провал/timeout;
- после результата показывается понятный outcome text;
- completion отмечается в состоянии цикла.

Если делаешь новую мини-игру без программирования, лучше копировать ближайшую
готовую lab-сцену и менять тексты/визуал.

## Feeding Холодильник

1. Скопируй `objects/interactable/templates/feeding_fridge_template.tscn`.
2. В Inspector настрой:
   - `minigame_scene`;
   - `food_scenes`;
   - `food_count`;
   - `andrey_face`;
   - `background_texture`;
   - звуки и сообщения.

Каждая food scene должна быть настоящим food item. Если добавляешь новую еду,
удобнее скопировать существующую еду из `levels/minigames/feeding/food/`.
При поедании еды (`eat_me()`) автоматически спавнится эффект крошек (`FoodCrumbsEffect`),
который нарезает мелкие кусочки из текстуры еды и симулирует их быстрое падение вниз.

## Холодильник После Лабораторной

Если холодильник должен открыться только после одной или нескольких lab:

1. У ноутбука проверь `lab_completion_id`.
2. У холодильника добавь этот ID в `required_lab_completion_ids`.
3. Убедись, что ноутбук и холодильник находятся в той же сцене.

Тесты проверяют, что required lab IDs реально существуют.

## Code Lock Холодильник

Для холодильника с кодом нужны:

- `access_code`;
- code lock scene;
- понятное сообщение игроку;
- корректная реакция на unlock.

Если нет особой причины, копируй уже настроенный code-lock холодильник.

## Финальный Холодильник

Финальный холодильник использует отдельную финальную feeding-мини-игру и влияет
на концовку. Его не стоит использовать как обычный холодильник в новом уровне.
Для обычного контента бери feeding template.

## Gamepad И Steam Deck

Мини-игры должны проходиться без мыши:

- confirm - A/Space;
- cancel - B/Esc;
- secondary - X/C;
- навигация - arrows/d-pad/stick;
- tabs - LB/RB или Q/E.

После изменения мини-игры проверь мышь/клавиатуру и gamepad-сценарий.

## Чеклист

- Ноутбук запускает нужную мини-игру.
- Таймер и штрафы выглядят разумно.
- Успех засчитывается только один раз.
- Провал/timeout не выдаёт награду второй раз.
- Холодильник не открывается до нужной лабораторной.
- Еда, лицо и background назначены.
- Все тексты есть в localization CSV.
