# Добавление Уровня

Новый уровень лучше делать из шаблона. Это самый короткий путь без скрытых
ошибок в Player, кровати, музыке и переходах.

## 1. Скопировать Шаблон

1. В Godot открой FileSystem.
2. Найди `levels/templates/cycle_level_template.tscn`.
3. Сделай Duplicate.
4. Перенеси копию в `levels/cycles/`.
5. Назови файл по схеме `level_XX_name.tscn`, например
   `level_15_basement.tscn`.

Важно: игровые уровни в этой папке должны начинаться с `level_`.

## 2. Настроить Root Уровня

Открой новую сцену и выбери корневой узел уровня. В Inspector проверь:

- `cycle_number` - номер уровня/цикла, больше 0;
- `timer_duration` - время цикла, 0 или больше;
- стартовый hint/subtitle - только если он реально нужен;
- exported `*_path` поля - если поле заполнено, оно должно указывать на
  настоящий узел в этой сцене.

Если поле с путём пустое и ты не уверен, optional оно или обязательное, лучше
сравни с соседним похожим уровнем.

## 3. Поставить Игрока

В сцене должен быть ровно один Player instance:

```text
res://player/player.tscn
```

Обычно он уже есть в шаблоне. Передвигай его в редакторе, не заменяй на новый
самодельный узел.

## 4. Настроить Кровать И Переход

В уровне должна быть хотя бы одна кровать, которая ведёт дальше.

1. Выбери узел кровати.
2. В Inspector найди `next_level_path`.
3. Укажи путь к следующему уровню или концовке.

Нельзя оставлять переход на саму себя, если это не специальная заблокированная
кровать. Для декоративной/запрещённой кровати используй `block_sleep=true` и
понятное сообщение в `blocked_sleep_message`.

## 5. Добавить Музыку Уровня

Если уровню нужна фоновая музыка:

1. Добавь или найди узел `LevelMusic`.
2. В поле `stream` выбери аудио.
3. Настрой `play_on_ready`, `continue_on_level_change`, `fade_time`,
   `volume_db`.

Если `play_on_ready=true`, `stream` должен быть назначен.

## 6. Добавить Объекты

Для интерактивов используй шаблоны из `objects/interactable/templates/`.
Для дверей, ноутбуков, холодильников и ключей лучше копировать похожий объект
из существующего уровня и затем менять Inspector поля.

Главное: если объект имеет поле `NodePath`, перетащи нужный узел из Scene tree
в это поле. Не оставляй путь "на потом", если от него зависит gameplay.

## 7. Проверить Уровень

Чеклист:

- уровень открывается без ошибок;
- игрок появляется в нужном месте;
- кровать ведёт в нужную сцену;
- двери ведут к правильным markers;
- музыка играет/останавливается как задумано;
- все подсказки читаемы;
- новые тексты добавлены в localization CSV;
- `bash tests/run_tests.sh` проходит перед коммитом.

## Частые Ошибки

- Две копии Player в одной сцене.
- Кровать ведёт на саму себя.
- Дверь открыта, но `target_marker` пустой.
- Музыка активна, но stream не назначен.
- NodePath указывает на старое имя узла после переименования.
- Русский текст виден игроку, но отсутствует в `global/localization/texts.csv`.
