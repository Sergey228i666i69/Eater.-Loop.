# Быстрый Старт

## Что Нужно Установить

- Godot 4.x, желательно та же версия, которой проект сейчас открывается.
- Git.
- Git LFS, потому что картинки, звуки и часть бинарных ресурсов лежат через LFS.

После первого clone выполни в папке проекта:

```bash
git lfs install
git lfs pull
```

Если этого не сделать, вместо части ассетов будут маленькие pointer-файлы, и
сцены могут выглядеть сломанными.

## Как Открыть Проект

1. Запусти Godot.
2. Нажми Import.
3. Выбери файл `project.godot` в корне проекта.
4. Открой проект.
5. Нажми Play. Главная сцена уже настроена как
   `levels/menu/main_menu.tscn`.

## Где Что Лежит

- `levels/cycles/` - игровые уровни.
- `levels/menu/` - главное меню, пауза, настройки.
- `levels/endings/` - концовки и титры.
- `objects/interactable/` - двери, холодильники, ноутбуки, ключи, notes,
  trigger-объекты.
- `levels/minigames/` - мини-игры.
- `player/` - игрок, фонарик, выносливость, визуальный риг.
- `enemies/` - враги.
- `global/localization/texts.csv` - тексты RU/EN.
- `music/` - музыка.
- `tests/` - проверки проекта.
- `docs/human/` - понятные инструкции.
- `docs/ai/` - строгие правила для агентов и программистских изменений.

## Базовое Управление

Основные actions заданы в `project.godot`:

- движение: `A/D`, стрелки, gamepad stick/d-pad;
- взаимодействие: `E`, Space, gamepad A;
- фонарик: `F`, gamepad X;
- бег: Shift, gamepad left stick press;
- пауза: Esc, gamepad menu/start;
- мини-игры: A/B/X, arrows/d-pad/stick, LB/RB в зависимости от схемы.

Если меняешь управление, обновляй `project.godot` и обязательно запускай тесты:
проект проверяет, что runtime-код не ссылается на несуществующие actions.

## Как Безопасно Работать С Файлами

- Новые уровни и объекты лучше создавать через Duplicate существующего шаблона
  в Godot FileSystem dock.
- После добавления картинки или звука дождись, пока Godot создаст `.import`.
- Не удаляй `.import` и `.uid` файлы вручную.
- Не переименовывай крупные сцены из Finder без проверки в Godot: у сцен много
  ссылок и NodePath.

## Минимальная Проверка После Изменений

Для маленькой правки в сцене:

1. Открой сцену в Godot.
2. Убедись, что нет красных ошибок в Output.
3. Запусти игру или конкретную сцену.
4. Проверь действие руками.

Перед коммитом или передачей кому-то:

```bash
bash tests/run_tests.sh
```
