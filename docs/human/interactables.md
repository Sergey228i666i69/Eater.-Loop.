# Интерактивы, Двери И Ключи

Интерактив - это объект, с которым игрок взаимодействует через `E`/Space/A.
В проекте этим управляет общий `InteractionManager`, поэтому один input должен
выбирать один ближайший доступный объект.

## Простой Интерактив

1. Скопируй `objects/interactable/templates/basic_interactive_template.tscn`.
2. Перенеси копию в подходящую папку внутри `objects/interactable/`.
3. Открой сцену.
4. Настрой в Inspector:
   - `prompt_text` - что игрок увидит рядом с объектом;
   - `one_shot` - можно ли использовать объект только один раз;
   - `CollisionShape2D` - зона, где объект доступен;
   - визуальный `Sprite2D` или другой видимый узел.

Если текст видит игрок, добавь его в `global/localization/texts.csv`.

## Зависимость От Другого Объекта

Если объект должен стать доступным после другого действия:

1. В поле dependency выбери объект, от которого зависит интерактив.
2. Выбери condition:
   - `COMPLETED` - после успешного завершения;
   - `INTERACTION_REQUESTED` - после самой попытки взаимодействия.

Для дверей, холодильников и ноутбуков почти всегда нужен `COMPLETED`.

## Дверь

Для обычной двери проверь:

- `target_marker` - куда перенести игрока;
- locked-флаги - закрыта ли дверь;
- `required_key_id` - нужен ли ключ;
- сообщения блокировки - что показать игроку.

Если дверь не должна вести никуда, лучше сделать её явно locked. Открытая дверь
с пустым или self-target путём - частая ошибка.

## Ключ И Закрытая Дверь

Если дверь требует ключ:

1. У двери задай `required_key_id`, например `storage_key`.
2. В той же сцене создай источник этого ключа:
   - обычный Key;
   - Note с `reward_key_id`;
   - SearchSpot с `key_id`;
   - мини-игру поиска через SearchKeyManager.
3. Убедись, что ID совпадает символ в символ.

Тесты проверяют, что у key-door есть источник ключа в той же сцене.

## Поиск Ключа

Для SearchKeyManager:

- список `search_spots` должен быть непустым;
- каждый путь должен вести к настоящему `SearchSpot`;
- у каждого `SearchSpot` есть `key_id`, `key_texture`, мусорные текстуры и
  корректная мини-игра.

Если не хочется настраивать с нуля, копируй похожую сцену поиска из уже
существующего уровня.

## Подсказка В Нужном Месте

Если подсказка появляется далеко от объекта:

- проверь позицию CollisionShape2D;
- проверь prompt anchor, если он есть;
- сравни с похожим объектом в соседней сцене.

## Чеклист Перед Сохранением

- Объект подсвечивается только когда игрок рядом.
- Нажатие взаимодействия срабатывает один раз, если `one_shot=true`.
- Закрытый объект показывает понятное сообщение.
- После успешного действия зависимые объекты открываются.
- Не появляется два prompt-а одновременно на один input.
- Все видимые строки есть в localization CSV.
