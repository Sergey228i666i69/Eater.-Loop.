# AI README

Эта папка - рабочая документация только для ИИ-агентов и разработчиков,
которые меняют проект как кодовую базу. Человеческие инструкции без лишней
технической детализации находятся в `../human/`.

## Быстрый Вердикт

Проект поддерживаемый, но дорогой в изменениях. После ремонтных проходов
главные runtime-дыры закрыты, локальный тестовый слой есть, `project.godot`
явно задаёт entrypoint и autoload-и, а многие хрупкие scene contracts уже
закреплены тестами. Остаточная проблемность - около 5/10.

Главная опасность не в запуске игры, а в случайном разрушении контрактов:
`NodePath`, имена детей в больших сценах, крупные facade-классы и player-facing
тексты без локализации.

## Порядок Чтения

1. `agent-operating-rules.md` - как работать в ветке, что можно менять, как
   не повредить чужие изменения.
2. `project-map.md` - где entrypoint, autoload-и, основные папки, шаблоны и
   старые справочные документы.
3. `architecture-contracts.md` - публичные facade API, pause/music/input/UI
   правила, запрет private/stringly coupling.
4. `content-authoring-contracts.md` - правила для уровней, интерактивов,
   мини-игр, света, локализации, ассетов и validators.
5. `verification.md` - какие команды запускать, как чинить import/UID drift,
   что считается достаточной проверкой.
6. `refactor-roadmap.md` - где оставшийся риск и как резать крупные классы
   без регрессий.

## Источники Подробностей

Новые AI-доки - нормативный вход. Старые документы в `../` остаются
исторической и технической справкой:

- `../audit_multiagent_summary.md`
- `../architecture_overview.md`
- `../content_authoring_guide.md`
- `../audio_system.md`
- `../minigame_gamepad_system.md`
- `../level_end_endings.md`
- `../macos-dmg-export-fix.md`

Если новая AI-документация и старый audit-файл расходятся, сначала проверь
код и тесты, затем обнови документ, который устарел.

## Что Нельзя Делать По Памяти

- Не заявляй, что suite зелёный, без свежего запуска.
- Не меняй `project.godot`, import cache, UID sidecars или крупные `.tscn`
  сцены "заодно".
- Не исправляй чужие dirty changes, если пользователь явно этого не просил.
- Не добавляй player-facing текст без локализации.
- Не добавляй новый скрытый scene contract без focused validator.
